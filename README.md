# Retr0 • PS4 Host

Site de PS4 de Retr0 (Davi Moreno). Ao abrir, a página identifica o firmware pelo navegador do console e destaca o host compatível; o desbloqueio nunca começa sozinho no menu.

Base técnica, exploits e payloads: PlayStation Pulse / sudoBlackArch (https://github.com/sudoBlackArch/sudoblackarch.github.io). Os arquivos de execução foram mantidos como no original; esta versão muda a apresentação e a detecção do menu.

No navegador do PS4, abra:

```
https://retr0dedsec0.github.io
```

Escolha o firmware do seu console, siga as instruções da página e, se quiser, salve o endereço nos favoritos para abrir com um toque.
